# Synthetic example data

A fabricated table so that every example and every vignette runs without
a database. On purpose, it carries the defects real data has: sentinel
`-999` in several masses (`vl_hist_*`), missing values (`vl_parcial_*`),
a column that only degrades in the last period (`vl_tardio`), constant,
near-constant, exact duplicate, high cardinality, a redundant pair and
pure noise. Without them, the audit funnel would have nothing to show.

## Usage

``` r
scr_demo
```

## Format

A `data.frame` with 4,200 rows and 41 columns:

- `id`:

  Identifier (never a candidate; goes in `drop`).

- `ref_date`:

  Monthly reference date, six periods; the key of the out-of-time split.

- `vl_score_01` to `vl_score_12`:

  Numerics with decreasing signal.

- `vl_hist_01` to `vl_hist_05`:

  Numerics with an increasing mass of sentinel `-999`; the signal is in
  the absence.

- `vl_parcial_01` to `vl_parcial_03`:

  Numerics with genuine `NA`.

- `vl_tardio`:

  Numeric with `NA`/sentinel in the last period only.

- `vl_ruido_01` to `vl_ruido_06`:

  Pure noise.

- `vl_constante`, `vl_quase_const`, `ds_constante`, `vl_duplicada`,
  `vl_redundante`, `ds_alta_card`:

  Structural pathologies.

- `ds_regiao`, `ds_faixa`, `ds_canal`, `ds_optin`:

  Categoricals with signal; `ds_optin` has `NA`.

- `default`:

  Risk target (0/1, about 10% events).

- `churn`:

  Propensity target (0/1, about 25% events), for the portfolio examples.
